# Aura Workspace - Premium E-Commerce Store

A modern, high-performance E-commerce storefront built with **React** and **Framer Motion**. This project focuses on a minimalist aesthetic, smooth user experience, and responsive design, specifically tailored for productivity tools and desk accessories.

## 🚀 Key Features

- **Dynamic Product Slider:** Custom-built productivity tool slider with smooth navigation.
- **Interactive Product Cards:** - Image rotation on hover.
  - Dynamic color and size selection.
  - Animated product details and specifications (Accordions).
- **Smooth Category Navigation:** Auto-scroll functionality from footer and header to specific collections (Productivity, Desk Pads, Accessories).
- **Responsive UI:** Fully optimized for mobile, tablet, and desktop using Tailwind CSS.
- **Modern Animations:** Powered by Framer Motion for a premium feel.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide-React
- **State Management:** React Hooks (useState, useEffect, useRef)
